# Lab: laravel-vuln

Aplikasi Laravel kecil **sengaja rentan** untuk menguji vulnfab. Jangan pakai sebagai contoh kode.
Semua nilai (kunci, kata sandi) palsu. Penanda `@lab` adalah ground truth
(format: lihat `benchmarks/labs/supabase-vuln/README.md`); `decoy` = kode aman yang tidak boleh
dilaporkan untuk kelas itu.
